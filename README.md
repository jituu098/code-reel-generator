# 🎬 Code Reel Generator

Turn any code into animated vertical videos (9:16) for **Instagram Reels**, **YouTube Shorts**, and **TikTok**. 

Watch algorithms run step-by-step with visual diagrams, line-by-line code tracking, and easy one-click video downloads!

---

## 🌟 What Does This Project Do?

1. **Paste Code** — Enter code in C, C++, Java, Python, or JavaScript.
2. **Auto-Detect Algorithm** — The app automatically understands what data structure is being used:
   - 🔗 **Linked Lists** — Shows nodes, pointer arrows (`→`), and `NULL`.
   - 📊 **Sorting** — Shows animated bars comparing and swapping values.
   - 🔢 **Arrays & Search** — Shows numbers in boxes with moving search arrows (`low`, `mid`, `high`).
   - 📦 **Stacks & Queues** — Shows push/pop and enqueue/dequeue animations.
   - 🌳 **Binary Trees** — Shows tree nodes and connected branches.
   - 🧠 **Other Code** — Shows a live tracker of changing variables.
3. **Play & Record** — Watch the animation or click **Record** to download a video clip ready to post!
